# Veriscope Claim Compass

Build VeriScope from the attached master prompt, starting with the core flow: landing page, sign-in, and one investigation end to end (multi-source collection, claim extraction, information gaps, conflicts, outdated information, and the next-best-verification list) with the analysis dashboard. Build it on Lovable's stack (React, TypeScript, Tailwind, shadcn, Lovable Cloud) in place of the FastAPI, Celery, Redis, and Sentence Transformers stack in the spec. Use demo mode until search API keys are added.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://veriscope-claim-compass.lovable.app
